# hxwl-08 葡萄酒盲品训练

盲品看板：酒款资料核验与训练批次闭环系统。

## 技术栈

React 19 + Vite 7 + TypeScript + 纯 CSS，localStorage 持久化（无后端）。

## 分层结构（数据 / 校验 / 页面分开实现）

```
src/
├── data/                 # 数据层：结构与数据，不含规则与 UI
│   ├── types.ts          # 酒款、版本、批次、冲突等类型与字段/规则文案
│   ├── appellations.ts   # 法定产区目录（产区 ↔ 法定品种绑定表）
│   └── seed.ts           # 初始种子数据（含一款三规则全违反的样例）
├── domain/               # 校验层：纯函数，不依赖 React / DOM
│   ├── validation.ts     # 三条入训规则 + 冲突索引 + 入训池判定
│   └── batches.ts        # 抽取（三款不同产区、未归档去重）+ 状态流转闸门
├── state/                # 状态层：reducer 状态机、版本链、localStorage 落盘
│   ├── store.ts
│   └── CellarContext.tsx
├── components/           # 页面层：录入、冲突清单、酒款库、批次看板
└── App.tsx
```

## 业务规则

1. **录入绑定**：产区（自动绑定法定品种表）、法定品种、年份、灌装年份、适饮区间。
2. **不得入训的三种冲突**（可存为待核资料，但不进入训练池）：
   - 品种不符法定产区（品种不在产区法定品种表内）；
   - 年份早于灌装年份；
   - 适饮区间倒置（起始晚于截止）。
   
   冲突清单列出：酒款、字段、原值、违反规则与说明。
3. **训练抽取**：每批三款且分属不同产区；同一酒款在未完成（未归档）批次中只出现一次；只从核验通过的入训池抽取。
4. **闭环流转**：训练中（三款全部完成）→ 提交讲师复核 → 讲师署名复核通过后归档；归档后酒款释放回可抽取池。
5. **复核修正**：讲师在复核中可修正酒款，必须填写原因；修正后生成新版本（版本号 +1、带原因、带时间），旧版本全部保留，批次内旧题快照保留并标记“旧题已留存”。修正后仍违反规则则拒绝产生新版本。
6. **刷新一致**：每次状态变更写入 localStorage，刷新后酒款、批次、版本链完全恢复。
